# Sant Ana Alchemy — Crafting Engine

Foundry VTT 14 · dnd5e · English / Português (Brasil)

## English

This repository is being prepared for the public distribution of the free Sant Ana Alchemy crafting engine.

The free module contains the crafting engine and the Water Preservative demonstration: two ingredients, one formula, its physical recipe book, and the finished product. Its interface supports English and Brazilian Portuguese.

The complete C1–C5 content packs and the foraging module remain separate bonuses supplied to purchasers of the book. They are not included in this public repository.

**Release status:** no installation release has been published here yet. The installation and update URLs, distribution license, and live crafting validation are still being prepared. Foundry catalog listing has not been requested.
